## How to run the demo

Start the server:

```
$ cd $ROOT
$ bun index.ts
```

You want to open a browser and navigate to `localhost:8080`.

![index.ts initial](https://kazurayam.github.io/websocket-demo/images/001_index.ts_initial.png)

Now you are ready to type a message and submit it.
